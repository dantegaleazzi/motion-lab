# Portal Motion Lab

A small, open-source playground for experimenting with card motion on the web. It includes a portal tunnel inspired by an early Sted landing-page exploration, plus orbit and cascade variations.

The speed control scales the full animation loop while preserving the spacing between cards. Demo cards and their copy are fictional. The project uses no framework, build step, external service, or Sted product assets.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Remix

- Change the loop duration, card spacing, or motion paths in the inline script.
- Replace the sample cards in `samples` with your own content.
- Add new motion modes alongside `portal`, `orbit`, and `cascade`.

The playground starts paused when the operating system requests reduced motion. Visitors can start it with the play control.
