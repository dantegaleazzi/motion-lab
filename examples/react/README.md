# React example

From the repository root, with a current Node 22 or 24 release:

```sh
npm ci
npm run dev:react
```

Open http://127.0.0.1:5188/. This Vite example runs in React Strict Mode and uses the real component, shared engine, styles and local sample photos. Try the six modes, pause, manual steps and unmount/remount. It is a development example, not a prebuilt page on GitHub Pages.

For your own app, copy the files listed in the [React guide](../../react/README.md); you do not need to copy this Vite example or install its development dependencies.
